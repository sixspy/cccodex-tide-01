# 潮位报文归集台

港务水文组收到各潮位站的定长报文。归集员把一批报文贴进来，系统按站码和时刻解析、去重，能落库的写入归集表，列数不对、站码坏了或时刻已经存在的行单独列出。

解析完先问站码目录：目录外的编码不许悄悄入库。未入册编码的去向只有两种——「挡在未接纳」或「先落库再在详情标未入册」，由归集员在目录设置里选定，当天选定后不许再改。贴入时带的去向与目录设置不一致，未入册的行停住并记「目录去向不符」。两人同时递同一个新站码，只保留先拿到锁的一行，后到的记「目录争用」。空编码不能写进目录。目录还在保存时，这一站的报文不准落库（记「目录保存中」）。

## 启动

```bash
docker compose up --build
```

健康检查：`GET http://localhost:8221/api/health`

## 页面

- **已收列表**：每批写出站码、落入行数、未入册行数和去向名。
- **报文详情**：已入册与未入册分开列，未入册行展开原因。
- **目录设置**：查看目录、定下今日去向（当天锁定）、递新站码。
- **未入册卡片**：汇总当前批次的未入册站码与行，先落库的和被挡下的分开展示。
